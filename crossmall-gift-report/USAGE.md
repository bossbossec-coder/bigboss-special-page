# 使い方

## 昨年分をまとめてダウンロードする

1. `run_gift_csv.bat` をダブルクリックします
2. 黒い画面が開いたら `1` を入力してEnterキーを押します
3. 「パスワード:」と表示されたら、クロスモールのパスワードを入力してEnterキーを押します
   (入力した文字は画面に表示されませんが、正しく入力されています)
4. 「パソコンに保存しますか?」と聞かれたら、毎日の自動実行も使う場合は `y` を入力します
5. ブラウザが開き、自動でログイン→1日ずつ検索→CSV出力が繰り返されます
   (78日分×5店舗=390件あるため、しばらく時間がかかります。ブラウザには触らないでください)
6. 「完了しました」と表示されたら終了です

ダウンロードしたファイルは `downloads` フォルダに
`ギフト_2025-10-15_ビッグボス楽天.csv` のような名前で保存されます。

## 途中で止まった場合

画面に `[エラー]` と表示された場合は、ブラウザの画面を確認してからEnterキーを押してください。
もう一度 `run_gift_csv.bat` を実行して `1` を選ぶと、**ダウンロード済みの日は飛ばして**
続きからダウンロードします。
うまくいかない場合は、表示された内容(または `gift_csv_log.txt` の中身)を伝えてください。

## 特定の日だけ取り直す

`run_gift_csv.bat` を実行して `3` を選び、開始日・終了日を入力します。
「取り直しますか?」に `y` と答えると、ダウンロード済みの日も上書きします。
