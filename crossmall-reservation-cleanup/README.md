# 予約商品名の予約テキスト削除 (CrossMall)

発売日の翌朝に、予約商品の商品名から予約用テキストを削除して全店舗へ出品処理する。

## 処理の流れ
1. 商品一括処理 → 店舗「ビッグボス楽天」、商品名 `【予約】【<昨日の日付>`、在庫「有」で検索
2. 結果の Mark「予約Claude」(chk1100) をチェックして更新
3. 各商品の店舗別詳細編集で `【予約】` と `【<日付>限定発売/新発売】` を削除、出荷リードタイム(IAS/BSH)=在庫あり時 / 納期管理番号=3 を入力して更新
4. ドリームクラフト → 同様(Mark「有」で検索)
5. Yahoo / wine.com → `<日付>限定発売 `(後ろの半角スペース1つ)のみ削除して更新
6. Wowma / Wowma2店舗目 → `【予約】`・`【日付…】`削除、販売方法区分=通常販売、お届けリードタイムID=2、発送日ID=2(商品名に IAS があれば IAS)
7. 表示商品を全選択 → 一括出品処理 → 全選択 → 処理開始
8. Mark「予約Claude」(Mark有)の商品のチェックを外して更新(失敗があった日は外さず翌日以降に再処理)

## 使い方
- 前提: `自動化用Chrome起動.bat` で Chrome(ポート9222)を起動し、クロスモールにログイン済み
- `pip install websocket-client`
- 動作確認: `python reservation_cleanup.py --dry-run`(変更内容をログに出すだけ。更新・出品はしない)
- 取りこぼし救済: `--days 3`(昨日〜3日前が発売日の商品も対象)
- ログ: `logs/YYYYMMDD.log`。終了コード 0=成功 / 1=失敗あり / 2=ログイン切れ

## タスクスケジューラ
- 操作: プログラム `cmd.exe`、引数 `/c "…\予約テキスト削除_実行.bat"`
- トリガー: 毎日 6:15
- 「ユーザーがログオンしているときのみ実行する」
- `.bat` は日本語を含むので CP932/CRLF のまま編集すること

## 追加: 出荷日表記の削除 (Yahoo / wine.com のみ)
予約テキスト削除のあとに続けて実行する。
1. Yahoo → 店舗商品名が `<当日のM月D日>出荷` (例 10/26の朝は `10月26日出荷`、ゼロ埋めなし。前日にするなら `--ship-offset 1`) の商品を検索 → Mark(予約Claude)を付けて更新
2. 商品名の先頭の `10月25日出荷 ` を、後ろの半角スペース1つ込みで削除して更新(他の文字・スペースは触らない)
3. wine.com でも同様
4. 名前を消すと検索に出なくなるため、Mark有で各店舗を表示 → 全選択 → 一括出品処理。**出品先はその店舗だけ**(全店舗には出さない)
5. Markを外す(失敗があった日は外さない)
- 試す: `python reservation_cleanup.py --dry-run`(当日の出荷日表記が対象。日付指定は `--date 2026-10-26`)
