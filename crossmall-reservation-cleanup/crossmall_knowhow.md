# CrossMall 自動化ノウハウ(予約テキスト削除・出荷日表記・最強配送の作業で分かったこと)

別のセッションでクロスモールの自動化を頼むときは、このファイルを Claude に読み込ませる。
(最初の「CrossMall / お店net 自動化ノウハウ」MD の続編。重複を避け、今回の作業で新しく分かったことを中心にまとめている。)
画面の部品(ID・セレクタ)の一覧は `.claude/skills/crossmall-ui/SKILL.md` を参照。
✔ = 実画面で動作確認済み / 未確認のものは「要確認」と書く。

## 1. 検索(商品一括処理画面)
- **前回の検索条件が画面に残る。** 商品コード(`item_cd1` / `item_cd2` / `item_cd_plural`)や Mark の選択(`mark_set1100`)が残ったまま検索すると、結果が絞られて**0件**になる。検索のたびに、使わない条件は必ず空にする ✔
  - 実例: 「予約Claude=有」が残ったまま商品名で検索 → 本当は29件あるのに0件
  - 前日の最後の検索(Mark有)が、翌朝の最初の検索に残る点にも注意
- **検索結果の表示に数十秒かかる。** 固定の待ち時間で「0件」と判断すると誤判定になる ✔
  - 読み込み中表示(`.x-mask`、Ext の store の読み込み状態)が終わるまで待つ。読み込み表示が見えない場合は、0件を確定する前に最大40秒待つ
- 店舗の切替(`#shop_id`、`chngShop()`)でページが再読込される。検索は `onSrch()`。1店舗の切替+検索で約20〜50秒。
- 店舗商品名の検索は**部分一致**。「全角半角:区別する」の設定があるので、全角数字だと半角で検索しても出ない(要注意)。
- 検索条件の「商品登録」欄(`#stc_flag`、1=無/2=有)は、予約処理では「有」で絞っている。
- **商品名は店舗ごとに別。** 同じ商品でも、楽天は `【予約】【日付新発売】…`、Yahoo は `日付限定発売 …`(【予約】なし)、Wowma は `【予約】…` と、表記が違う。

## 2. Mark(予約Claude = Mark 1100)の使い方
- **Mark は商品に付き、店舗をまたいで共通。** 楽天で付けると、ドリームクラフト以降の店舗でも「Mark有」で検索すると同じ商品が出る。外すときも1か所で外せば全店舗で外れる ✔
- 付ける/外す方法: 検索結果の各行の `input.chk_mark#chk1100_<行>` を1件ずつ直接クリックし、「更新」(`input[name=rgst]`、`onSubmit()`)を押して保存する ✔
- **すでにチェック済みの行をクリックすると外れてしまう。** 「新規にチェックした件数」ではなく「チェック済みの合計」で成功を判断する(0件=失敗扱いにすると誤エラーになる) ✔
- **商品名を変えると、名前では検索に出なくなる。** 名前を消した後の出品処理は、Mark有で再検索して表示させてから行う ✔
- Mark は、名前を変えた商品を追いかけるための「目印」。処理が全部終わったら必ず外す。失敗があった日は外さず、翌日以降に再実行できるようにする。
- 前日の処理が途中で止まると Mark が残る。残った Mark だけを外すオプションを用意した(`--clear-marks-only`) ✔
- 残った Mark を使う処理(例: 楽天への最強配送)は、関係ない商品に作用する恐れがある。**今回のYahoo更新分の商品コードだけを対象にして誤爆を防ぐ。** ✔

## 3. 出品処理(一括出品処理)
- 出品の対象は「検索結果に表示されている商品のうち、行チェックを入れたもの」。行チェックは `.x-grid-row-checker` を1つずつ直接クリックする ✔
- 一括出品処理(`onMultiMallUpload()`)の確認画面は、ポップアップの場合とインラインの場合がある。両対応にする。
- 確認画面の「全選択」(`allRow(true)`)は**全店舗**にチェックを入れる。店舗を限定したいときは、`select_shop_id_<店舗ID>` を個別にチェックし、**チェックされた店舗が想定と一致しなければ出品せずに中止**する ✔
- 店舗ごとに、その店舗の画面を表示して、その店舗だけに出品する形が安全(Yahoo → wine.com → 楽天 の順に ✔)。
- 行の商品コードは、行(`tr`)のテキストから `\d{13}[-\w]*` で取れる(例 `4901004006684-sbl-1`)。名前を変える前後でも同じコードで追える ✔

## 4. 店舗別詳細編集ポップアップ
- 商品名のリンク(`a[href*="doEditShopItem"]`)をクリックすると、別ウィンドウで開く ✔
- 更新後、ポップアップが**閉じなければ入力エラー**(文字数オーバー等)。JSダイアログのメッセージをログに残す。ダイアログは CDP で自動OKにする ✔
- 一度失敗しても、その場で1回だけやり直す。やり直しで二重に書き換えないよう、「すでに変わっている」ならスキップする判定にしておく ✔
- 店舗の型:
  - 楽天・ドリームクラフト: `mall_rakuten[item_name]` / 在庫あり時 出荷リードタイム `stock_shipping_lead_time_label` / 在庫あり時 納期管理番号 `stock_delivery_date_no`
  - Yahoo・wine.com: `mall_yahoo[item_name]`(更新は `checkSelectOptions`)
  - Wowma・Wowma2店舗目: `mall_basic[item_name]` / 販売方法区分「通常販売」`#kbn_09_1` / お届けリードタイムID `#char_13` / 発送日ID `#char_12`
- 名前の加工は、**消す文字だけ**を正規表現で厳密に指定する。他の文字・スペースには触らない ✔
  - 先頭の `10月25日出荷 ` を消すときは、続くスペースをまとめて消す(名前がスペースで始まらないように)
  - Yahoo の `日付限定発売 ` は、後ろのスペース1つだけ消す

## 5. 自動化の運用で分かったこと
- **他の自動化と同じ Chrome を使うと、ぶつかる。** 編集画面が見つからず失敗する(例: 19:20の別の自動化と重なった)。実行時間帯をずらす。失敗は1回だけやり直す。
- 1商品の失敗で全体を止めない。失敗は最後にまとめて報告する。ログイン切れだけは打ち切る。
- 実行時間の目安: 商品がない日は約5分(6店舗×検索)。商品が約30件あると、各店舗の編集と出品で10〜15分ほど長くなる。
- **ドライラン(`--dry-run`)では Mark が付かない**ため、Mark で検索する後続の店舗は0件になる。ドライランで確認できるのは「検索・商品名の変更案」まで。後続の確認は、**商品コードで絞った本番テスト**(`--only-codes`)で行う ✔
- 取りこぼし対策: `--days N` で、N日前まで遡って処理できる。
- ログ(`logs/YYYYMMDD.log`)に、変更前→変更後の商品名、検索件数、失敗の内容を残す。終了コード: 0=成功 / 1=失敗あり / 2=ログイン切れ。

## 6. Windows タスクスケジューラ・.bat(追加の学び)
- **フォルダ名・ファイル名に日本語が入っていると、`cmd.exe /c` で呼んだとき、すぐ失敗することがある**(1秒以内に終了、戻り値 2147942401)。**英数字のパス・名前にする**と解決した ✔
- 実行して「何も起きない」ときは、履歴タブの「操作が完了しました(201)」の**戻り値**と、手での実行結果を見る。手で `.bat` を実行して、画面に出たエラーを見るのが一番早い。
- ZIP を展開したときにフォルダが二重になりやすい。`dir` で中身を確認して、本物のフォルダを探す。
- `.bat` は CP932・CRLF で保存。拡張子が `.bat.txt` になっていないかも確認。
- 「ユーザーがログオンしているときのみ実行する」。Chrome(ポート9222)をログイン済みで開いておく。トリガーの時刻は24時間表記(16:15 と 6:15 を間違えない)。
- ブラウザの自動翻訳で、コードの文字(スペースなど)が変わって見えることがある。コードは選択コピーせず、ダウンロードボタンで保存する。

## 7. 今回の自動化の仕様(毎朝 6:15)
1. **予約テキスト削除**(前日が発売日の商品): 楽天で `【予約】【前日の日付` を検索 → Mark → 楽天/ドリクラ/Yahoo/wine.com/Wowma/Wowma2店舗目の商品名から予約テキストを削除、各店舗の項目を入力 → 一括出品処理 → Mark解除
   - 楽天・ドリクラ: 出荷リードタイム(在庫あり時)=`IAS`(商品名に『IAS』があれば)/ それ以外 `BSH`、納期管理番号=3
   - Wowma: 通常販売、お届けリードタイムID=2、発送日ID=2(『IAS』があれば `IAS`)
2. **出荷日表記の削除**(Yahoo・wine.com のみ、**当日**の日付): 商品名先頭の `10月26日出荷 ` を削除 → Yahoo・wine.com へ出品
3. **楽天の最強配送**(Yahooで更新した商品だけ): `【本州のみ 送料無料】`/`【送料無料】` の直前に `【最強配送】` を追加(二重不可、どちらもなければスキップ)、出荷リードタイム=`SAIKYO`、納期管理番号=`1` → Yahoo・wine.com・楽天に出品(各店舗だけ) → Mark解除
   - 文字数オーバー等で更新できない商品は、スキップせずエラーとして記録し、Mark は外さない
