# お歳暮ビールギフト特集 2026｜酒のビッグボス 楽天市場店

サッポロ（ヱビス）・アサヒ・キリン・サントリーのお歳暮（2026）・お年賀（2027）ビールギフト特集ページです。
元はプレモル単独の特集ページ（README.zip）で、4メーカー構成に作り替えました。

- `index.html` … 本番用ページ（HTML・CSS・JS を1ファイルにまとめています）
- `img/` … 公開時は一緒にアップしてください
  - `sapporo-〇〇.png`・`asahi-〇〇.png`・`kirin-〇〇.png`・`suntory-〇〇.png`（〇〇＝型番）… 商品画像（背景透過PNG）。
    各商品ページの最後にある「ロゴなし・白背景」の画像（楽天の店舗ページから取得）の白い背景を透明にしたもの
    容量を減らすため、長い辺を500pxに縮小し、色数を減らして圧縮しています（見た目はほぼ同じ。画像フォルダ全体で約4.6MB）。差し替える画像も、長い辺500px程度・圧縮済みにすると軽く保てます
    - ヱビス YE3D・YE4DN・YE5DT は商品ページに白背景・ロゴなしの画像が無いため、1枚目の画像を透過処理（YE3D・YE4DN はビッグボスのロゴが商品に重なっているため残っています。YE5DT はロゴを削除）
    - 黒ラベル KS3D（`sapporo-ks3d.jpg`）と PM6B（`set-pm6b.jpg`）は背景つきの写真しか無いため、JPGのまま
  - `asahi-5shu.png`・`kirin-3shu.png` … PICK UP のアサヒ・キリン（ご提供素材を透過処理）
  - `noshi-*.jpg`・`logo-bigboss-2026.png`・`bigboss-boss.png` … ビッグボスの素材

## 構成（メーカーの表示順：サッポロ → アサヒ → キリン → サントリー）
1. ヘッダー／FV：バナー画像（PC `img/fv-pc.jpg`・スマホ `img/fv-sp.jpg`。スマホは画像下の空き部分で商品が流れる）
2. メニュー（サッポロ／アサヒ／キリン／サントリー。スクロール追従）
3. ビッグボスのオリジナルのし
4. ご注文の流れ・お届け（会社・団体向けバナーはオレンジ）
5. PICK UP（3セット。背景はクリーム地に、左上は麻の葉＋金箔の帯、右下は網代＋金箔の帯で年末年始の雰囲気に。商品カードは白）
   - サッポロ ヱビス 5種セット … item.rakuten.co.jp/bigbossshibazaki/4901880884147-nsi/
   - アサヒ 5種セット（スーパードライ4・生ジョッキ缶2・ドライクリスタル2・ゴールド2・マルエフ2）… item.rakuten.co.jp/bigbossshibazaki/4901004045874/
   - キリン 3種セット（一番搾り6・晴れ風3・グッドエール3）… item.rakuten.co.jp/bigbossshibazaki/4901411132389/
6. メーカーから選ぶ（4枚）
7. **ご予算で選ぶ**：金額ボタン4つ（2,500円以下／2,500〜3,000円／3,000〜4,000円／4,000円以上）。押すと、4メーカーの該当商品が価格の安い順にボタンの下に表示されます。
   金額の区切りは `index.html` の `const bands=[...]` で変更できます。スマホ下部の固定ボタンもここへ移動します
8. 01 サッポロ／02 アサヒ／03 キリン／04 サントリー（すべて同じ形式の商品一覧）
9. 締め／フッター

## 商品データ
4メーカーとも `index.html` 下部の `const makerProducts=[...]`（並び順＝表示順）にまとめています。
- 価格・セット内容・型番・レビュー件数は、2026年10月27日時点の楽天の各商品ページより
- `url`：楽天の商品ページID（`item.rakuten.co.jp/bigbossshibazaki/〇〇/` の〇〇）。全商品で設定済み
- `rid`：お気に入り登録用の商品番号（ハートのボタン）／`id`：型番
- 「〇〇のギフトをもっと見る」ボタンは店舗のカテゴリページ（サッポロ 0000003654／アサヒ 0000003652／キリン 0000003655／サントリー 0000003653）に飛びます
- 商品カードの「商品ページを見る」ボタンは緑色
