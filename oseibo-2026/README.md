  - `asahi-5shu.png`・`kirin-3shu.png` … PICK UP のアサヒ 5種セット・キリン 3種セット（ご提供素材・背景透過）

## 商品データ
4メーカーとも `index.html` 下部の `const makerProducts=[...]`（並び順＝表示順）にまとめています。
- `url`：楽天の商品ページID（`item.rakuten.co.jp/bigbossshibazaki/〇〇/` の〇〇）。`null` の商品は「商品ページを見る」ボタンがショップ内検索（メーカー名で絞り込み）に飛びます
- `rid`：お気に入り登録用の商品番号（入れるとハートのボタンが付きます。いまはサントリーのみ）／`id`：型番（入れると表示）
- `inside`：セット内容／`when`：予約商品の発売日（日本時間0時から「発売中」に自動切替）
- サッポロ・アサヒ・キリンの価格・本数・レビューは、店舗の商品一覧のスクリーンショット（2026年10月27日時点）から入力。商品名は画像から判断した名前です
- 商品ページIDを設定済み：アサヒ 5種セット（4901004045874）、キリン 3種セット（4901411132389）、サントリー全商品
- サントリーの価格・レビューは2026年10月15日時点（元のページのデータ）
- キリン「一番搾り＆トロピカーナ ファミリーセット」は価格がスクリーンショットで切れていたため「価格は商品ページで」表示（ご予算ボタンの対象外）

## 公開前に確認する箇所
- 商品画像の差し替え（上記）
- PICK UP のサッポロ：商品名は同じ商品番号（JAN）の過去の出品から判断しています。画像も一覧から推測で選んでいるため、2026年の商品ページと合っているかご確認ください（価格は「商品ページでご確認ください」表示）
- 価格・発売日・在庫は変わることがあります。公開直前に商品ページと照合してください
