# お歳暮ビールギフト特集 2026｜酒のビッグボス 楽天市場店

サッポロ（ヱビス）・アサヒ・キリン・サントリーのお歳暮（2026）・お年賀（2027）ビールギフト特集ページです。
元はプレモル単独の特集ページ（README.zip）で、4メーカー構成に作り替えました。

- `index.html` … 本番用ページ（HTML・CSS・JS を1ファイルにまとめています）
- `img/` … 公開時は一緒にアップしてください
  - `sapporo-*.jpg`・`asahi-*.jpg`・`kirin-*.jpg` … 店舗の商品一覧のスクリーンショットから切り出した商品画像（約200px）。**画質が低いため、公開前に楽天の元画像に差し替えるのがおすすめです**（ファイル名を同じにすれば差し替えだけで反映されます）
  - `item-*.png`・`hero-limited.png`・`can-eto-*.webp`・`set-pm6b.jpg` … サントリーの商品画像（元ページのまま）
  - `noshi-*.jpg`・`logo-bigboss-2026.png`・`bigboss-boss.png` … ビッグボスの素材
  - `suntory-cp-30names.jpg`・`coupon-suntory-5off.jpg` … サントリーのキャンペーン・クーポン

## 商品データ
- サッポロ・アサヒ・キリン … `index.html` 下部の `const makerProducts=[...]`（並び順＝表示順）
  - `url` が `null` の商品は「商品ページを見る」ボタンが**ショップ内検索**（メーカー名で絞り込み）に飛びます。
    楽天の商品ページID（`item.rakuten.co.jp/bigbossshibazaki/〇〇/` の〇〇）を `url:'〇〇'` に入れると、その商品ページに直接飛ぶようになります
  - 価格・本数・レビューは、いただいた商品一覧のスクリーンショット（2026年10月27日時点）から入力。商品名は画像から判断した名前です
  - 在庫終了・売り切れだったヱビス 15本／20本セットは掲載していません
  - キリン「一番搾り＆トロピカーナ ファミリーセット」は価格がスクリーンショットで切れていたため「価格は商品ページで」表示
- サントリー … `const products=[...]`（元ページのまま）

## 公開前に確認する箇所
- **PICK UP の3商品**：商品名は同じ商品番号（JAN）の過去の出品から判断しています。2026年の商品ページの内容（商品名・セット内容）と合っているかご確認ください。価格は「商品ページでご確認ください」表示にしています
- **キリン スプリングバレーの画像**：手元に画像が無いため、仮の赤いパネルを表示しています。画像を `img/` に入れて、PICK UP 3 の `<div class="ph brandph" ...>…</div>` を
  `<div class="ph cut"><img src="img/ファイル名" alt="キリン スプリングバレー 3種セット" loading="lazy"></div>` に差し替えてください
- お気に入りボタンは、商品番号（iid）がわかるサントリーの商品のみ表示しています
- 価格・発売日・在庫は変わることがあります。公開直前に商品ページと照合してください
