方針：紺×金の高級感でプレモルが主役。1本の金の水引がカットをつなぐ。カット間はすべてクロスディゾルブ（約0.5秒）。
お歳暮カード画像はそのまま使わず、花柄部分だけを金色に染めてぼかした背景の質感（`assets/noshi-pattern.png`）として使用。

| カット | 時間 | 動き |
|---|---|---|
| 1 引く | 0.0–2.5s | 金の水引が左→右へ引かれ、光が追いかけて大きなプレモル缶が浮かぶ |
| 2 結ぶ | 2.5–5.0s | 水引がギフト箱の下をくぐる／「一年の、ありがとうを。」 |
| 3 迎える | 5.0–7.5s | 干支缶を大きく手前、香るエール干支缶は奥でボケ／「迎春」 |
| 4 注ぐ | 7.5–10.0s | グラスの大写し、金の粒が泡に／「いつもより、少しいいビールを。」 |
| 5 選ぶ | 10.0–12.5s | 5種セットにピント、左右のセットはボケ／「お歳暮に、プレモル。」 |
| 6 贈る | 12.5–15.0s | 缶＋グラス、水引が中央で結ばれる／「一年のありがとうを、とっておきのプレミアムビールで。」 |
