# 楽天 夜売価(時間指定の価格変更)

Excelに書いた時刻に、**ビッグボス楽天の価格だけ**を変えて出品し、戻す時刻に**元の価格**へ戻して出品します。
Yahoo・wine.com・Wowma・ドリームクラフトの価格には触りません(楽天とYahooなどは価格がそれぞれ違うため)。

## Excelの書き方

置き場所: `D:\楽天claude\楽天夜売価`(このフォルダの .xlsx を1つだけ置く)

| 列 | 見出し | 書くこと |
|---|---|---|
| A | 商品管理番号 | 例 `4901880200985-wk1` |
| B | 変更後の価格 | 例 `3500`(税込・数字だけ) |
| C | 変更する日時 | 例 `2026/11/20 21:00` |
| D | 戻す日時 | 例 `2026/11/20 23:59`(C より後にする) |
| F | 通常価格 | **メモ。プログラムは読みません** |
| G | SALE価格 | **メモ。プログラムは読みません** |

- 1行目は見出し。2行目から1商品1行。
- 同じ商品をもう一度セールにするときは、**新しい行を足します**(終わった行は残しておいて大丈夫です)。
- 元の価格は書かなくて大丈夫です。変える直前に、プログラムがクロスモールから読み取って記録します。戻すときはその記録を使います(F列は使いません)。
- 1つの行は、変更と戻しが1回ずつ行われたら終わりです。終わった行を書き換えても、もう一度は動きません。もう一度動かしたいときは、新しい行を足してください。

## 動き方

1. タスクスケジューラが、5分ごとにプログラムを起動します。やることがなければ、1秒ほどで終わります(Chromeにも触りません)。
2. **C列の5分前**になったら: 今の楽天の価格を読み取って記録 → B列の価格に変える → ビッグボス楽天だけに出品。
3. **D列の5分前**になったら: 記録しておいた元の価格に戻す → ビッグボス楽天だけに出品。
   (楽天への反映に数分かかるため、5分前から始めます。`config.json` の `early_minutes` で変えられます)
4. 毎朝 6:10〜6:50 は動きません(6:15の予約テキスト削除とぶつからないように)。この間に来た分は、6:50以降に行います。

## 安全のための決まり

- 書き換えるのは、ビッグボス楽天(店舗ID 5255)の「通常購入販売価格」だけ。編集を開く直前に、毎回、店舗がビッグボス楽天かを確かめます。
- 出品の確認画面で、チェックがビッグボス楽天**だけ**になっていなければ、出品しません。
- 次のときは、実行せずに `要確認.txt`(Excelと同じフォルダ)に書きます:
  - 価格が空欄・数字でない、戻す日時が変更する日時より前、同じ商品で期間が重なる行がある
  - 変更後の価格が、元の価格の半分より安い(打ち間違い防止)
  - 戻すときに、今の価格が「変更後の価格」と違う(手で変えられた可能性。上書きしません)
  - 3回続けて失敗した
  - クロスモールのログインが切れている
- 戻す日時を過ぎてから気づいた行(パソコンが止まっていた等)は、価格を変えずに飛ばします。

## はじめの準備(1回だけ)

1. このフォルダ(`rakuten-night-price`)の中身を、**英数字だけのフォルダ**に置きます。例 `D:\rakuten_yoru`
   - 日本語の名前のフォルダに置くと、タスクスケジューラから動かないことがあります(前回の予約テキスト削除で起きました)。
   - Excelは今のまま `D:\楽天claude\楽天夜売価` で大丈夫です。
2. コマンドプロンプトを開いて、次を1回実行します。

```bash
pip install websocket-client openpyxl
```

3. 自動化用のChrome(予約テキスト削除で使っているもの)で、クロスモールにログインしておきます。

## 試し方(本番の前に必ず)

コマンドプロンプトで `D:\rakuten_yoru` に移動してから行います。

```bash
cd /d D:\rakuten_yoru
```

1. Excelの読み取り結果を見る(Chromeには触りません):

```bash
python yoru_price.py --list
```

2. 練習モード(画面を読むだけ。保存も出品もしません)。`--now` の時刻は、Excelの C列の時刻にします:

```bash
python yoru_price.py --dry-run --now "2026-11-20 21:00"
```

3. 商品1点で本番の試し。試す商品の行だけを、数分後の時刻にしてExcelに書きます。
   変える前に、全店舗の価格を記録しておきます:

```bash
python yoru_price.py --snapshot 4901880200985-wk1
```

   時刻が来たら手で動かします:

```bash
python yoru_price.py
```

   変わったあとに、もう一度記録して、前回と比べます(ビッグボス楽天だけ「変わった」、ほかは「変わらず」なら正常):

```bash
python yoru_price.py --snapshot 4901880200985-wk1
```

## タスクスケジューラの登録

1. タスクスケジューラを開き、「タスクの作成」を押します。
2. 全般: 名前 `rakuten_yoru`、「ユーザーがログオンしているときのみ実行する」。
3. トリガー: 「新規」→「毎日」、開始 `0:00`。「繰り返し間隔」にチェックして `5分間`、継続時間 `1日`。
4. 操作: 「新規」→ プログラム `cmd.exe`、引数 `/c "D:\rakuten_yoru\run_yoru_price.bat"`。
5. 設定: 「タスクがすでに実行中の場合」は「新しいインスタンスを開始しない」。

## ファイル

| ファイル | 内容 |
|---|---|
| `yoru_price.py` | 本体 |
| `run_yoru_price.bat` | タスクスケジューラ用 |
| `config.json` | 設定(Excelの場所、何分前に始めるか、動かない時間帯 など) |
| `state.json` | 各行の状態と、記録した元の価格(自動で作られます。**消さないでください**) |
| `logs\YYYYMMDD.log` | 何かをした回だけ記録します |

`state.json` を消すと、元の価格の記録がなくなり、戻せなくなります。

## メモリーについて

常に動き続けるプログラムではありません。5分ごとに起動し、終わったらすぐ閉じます。
Excelは A〜D列だけを読み、Chromeは前からある自動化用のものを使います(新しいブラウザは開きません)。
